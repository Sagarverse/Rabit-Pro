How To Use Rabit, Step by Step

This guide walks through the full flow: first pairing, keyboard and touchpad usage, AI assistant workflows, URL handoff, automation tools, snippets, shortcuts, and settings customization.

Android Controller Bluetooth HID AI Assistant Mac + Android Targets

Quick Start

STEP 01

Install and launch

Install the latest APK, open Rabit, and grant requested permissions for Bluetooth and notifications.

STEP 02

Pair your target device

From the Pairing screen, select your Mac or Android target and confirm pairing prompts on both devices.

STEP 03

Start in Keyboard screen

After connection, enter the Keyboard module and test typing, modifiers, enter, and media keys.

Tip: if connection drops, return to Pairing and reconnect before testing advanced modules like automation or assistant typing.

Detailed Feature Walkthrough

Keyboard + Modifiers

Use the INPUT tab for standard keyboard entry.

  • Toggle modifier keys (Cmd, Ctrl, Shift, Alt) then press target keys.
  • Use system keys for navigation and app switching.
  • Use batch typing to send longer text quickly.

Touchpad (PAD Tab)

Use your phone as a pointer device.

  • Single tap for click, two-finger for scroll.
  • Use motion/air-mouse features if enabled in settings.
  • Disable PAD mode when done to save battery.

Assistant (AI)

Open Assistant to generate or refine text.

  • Ask for rewrites, summaries, or structured drafts.
  • Use Auto Push to type generated output onto your connected device.
  • Set response behavior in prompts/system instruction settings.

Snippets

Save frequently used text blocks for one-tap typing.

  • Create categorized snippets (email, code, replies).
  • Tap to inject content through HID typing.
  • Update snippets as reusable templates.

Shortcuts Guide

Use predefined shortcuts for faster navigation.

  • Review common productivity combinations.
  • Practice in a text editor before live work.
  • Use in combination with modifier lock for speed.

URL Handoff

Share a URL from Android and open it quickly on your connected Mac via keyboard macro flow.

  • Tap Share in mobile browser, choose Rabit Handoff.
  • Rabit opens browser launcher flow on the target.
  • URL is typed and submitted automatically.

Automation Module

Use in-app automation tools for your own devices.

  • Wake-on-LAN screen to wake supported machines.
  • SSH Terminal screen for authenticated remote commands.
  • Use only on systems you own or are authorized to manage.

Settings + Customization

Control feature visibility and personalization.

  • Enable/disable modules from Customization.
  • Configure profile and AI/API options.
  • Adjust usability features for your workflow.

How To Create Complex Macros In App

STEP 01

Open macro editor

Go to Automation screen, then open USER CUSTOM and tap +.

STEP 02

Use script commands

Write one command per line. Supported commands are KEY(...), TEXT(...), WAIT(...), and MEDIA(...).

STEP 03

Save and run

Give your macro a name, save it, then tap it from USER CUSTOM to execute the full sequence.

Example: Spotlight -> Terminal -> whoami

KEY(CMD+SPACE)
WAIT(300)
TEXT(Terminal)
KEY(ENTER)
WAIT(700)
TEXT(whoami)
KEY(ENTER)

Media Control Deck & Now Playing

STEP 01

Open Media Control Deck

From the app drawer, open Media Control Deck. Use Play/Pause, Volume, Previous, and Next controls to send HID media commands to your Mac.

STEP 02

Connect companion metadata channel

Run desktop-helper on Mac. It authenticates with bridge PIN and pushes NOW_PLAYING payloads so Rabit displays title, artist, and album live.

NOW_PLAYING JSON payload

{
  "type": "NOW_PLAYING",
  "title": "Song Title",
  "artist": "Artist",
  "album": "Album",
  "artworkBase64": "..."
}

AirPlay Receiver (Wi-Fi)

STEP 01

Open AirPlay Receiver screen

From drawer, open AirPlay Receiver and enable it.

STEP 02

Select Rabit on Mac

On macOS Control Center -> Sound, pick Rabit from available outputs on same Wi-Fi.

Current build includes RAOP discovery and foreground receiver lifecycle scaffold. Full ALAC/RAOP decode pipeline requires an embedded RAOP engine/library.

Troubleshooting

CHECK 01

Not connecting over Bluetooth

Verify Bluetooth is enabled on both devices, remove stale pairing records, then pair again from Rabit Pairing screen.

CHECK 02

No typing on target

Ensure the target input field is focused and Rabit still shows connected state in the header.

CHECK 03

Assistant response not typing

Open Assistant settings and verify Auto Push or manual send action is enabled for output transfer.

Best Practices

Use trusted devices

Pair only with your own systems or explicitly approved devices.

Keep prompts clear

For AI output, concise instructions improve typing reliability and formatting quality.

Save reusable flows

Move repetitive text actions into snippets and shortcuts to reduce manual work.
